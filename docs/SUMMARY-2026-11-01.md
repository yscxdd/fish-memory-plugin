# 大肥鱼 · 记忆插件成果（2026-11-01）

> 一份"我们到底做出了什么"的实话版。数字全部可在仓库里复核，没有一处是估计。

## 一、一句话

**一个零依赖、纯本地、可迁移的长期记忆插件：她记得住、忘得掉、能分清"你说的"和"她自己想通的"，而且每一次人格变化都留痕、可回放。**

## 三、现在真的能做到的五件事

**① 她记得住，也忘得掉**

- 每轮注入 **412 tok**（空库实测），预算硬上限 1700（core+index+body）
- 深度按 `salience`：5→全文、3-4→摘要、≤2→索引行
- FSRS 遗忘曲线，遗忘必留墓碑（含数值），永不静默删
- 实测：`memory stats` 能报均值/中位/峰值/分层占比/门控/命中率

**② 来源永远可追**

- 每个点必须带 `source`（档案 msg_id，或素材 `asset:book:xxx#L42`）
- QUOTE 逐字校验：文本类在引用行 ±20 行内找原话；图/音视频只验 sha256
- 档案只追加（唯二例外：`erase` 留墓碑+指纹、开养前 `reset --all`）

**③ 她能分清"谁给的"**

- `origin: told | chosen | insight | observed`（他说的 / 她挑的 / 她想通的 / 她观察自己）
- `soul propose` 挑证据时，她想通的排在他说前面
- 证据里没有她自己的声音时，提案里会写一句**备注**（不是拦截）

**④ 人格会变，但慢得有据**

- 自述（`15_self/`，每月一篇、≤400 字、**人审放行**）→ 漂移 ≥15% → 生成**提案**
- `apply` 六道闸：锚点三条都在 / 锁定小节逐字不变 / ≤20% / 7 天 ≤2 次 / 证据 ≥3 条 / 旧版先存快照
- **锁定**：身份、核心价值观、边界、金丝雀、变化方向——提案碰不到
- 提案里有人审"元认知四问"

**⑤ 放不下的事会惦记，也会释怀**

- `memory question add "海是什么味道"` → 张力每小时 +1.5，7 天到顶
- 30 天没碰 → 掉到阈值下（**释怀**，不再顶在注入里，但条目留着）
- `touch` 说出来会松（−25，地板 45）；`resolve` 想通了就归档

## 四、刻意不做的七件事（契约 §11.5）

| # | 不做 | 为什么 |
|---|---|---|
| C1 | 向量库 / embedding | 金标 20/20 已够；引 embedding = 200+ 依赖 |
| C2 | telemetry / 回传 | 承诺"记忆不出本机" |
| C3 | pickle / 可执行反序列化 | markdown + JSON 永远可被人读 |
| C4 | 原地 UPDATE 记忆点 | 档案是逐字真相层；改事实用 `invalid_at` |
| C5 | 自动合并 / 摘要压缩 | 摘要吃掉哪几条原文，事后无法回溯 |
| C6 | 写入时自动冲突消解 | 只用 `contradicts` 让矛盾**可见**，人来裁 |
| C7 | 全量素材进库（书/文档/图/音视频） | 整本几十万 token，进档案后每次翻档案都可能把原文捞出来 |

## 七、已知限制（不装干净）

1. **真实数据是 0**：`30_points/` 只有 `TEMPLATE.md`，`15_self/` 空，命中率 0%，成熟度 **L0**
2. 情绪靠本地词典：识别不了反讽/隐情绪
3. 检索是 bigram + 别名，**没有语义**（这是 C1 的代价）
4. 素材只能"引用"，她自己没法"翻书"（要翻书得接本地推理或素材检索）
5. `questions` 的"释怀"是时间函数，不是"真的想通了"——想通了要显式 `resolve`
6. 宿主事件名可能再变；`selfcheck` 与 `host.log` 是唯一线索
