# BACKLOG — 功能冻结与三件待办

> 冻结于 **v0.28.0**（2026-11-01）。不是"做完了"，是"**先别再往功能上加了**"。

## 为什么冻结

1. **真实数据是 0**：`30_points/` 只有 `TEMPLATE.md`，`15_self/` 空着，`memory stats` 的命中率是 **0%**。
   在这个状态下加功能，等于在没接数据线的板子上继续焊芯片。
2. **每加一件都带来新的 bug 面**。这一轮（0.20.2 → 0.28.0）我自己踩的坑：
   - 锚点比对把 `- ` 归一成 `-`，导致 apply 永远假拒绝
   - 20% 用"可变区"当分母，两行字被放大成 36%
   - `touch` 把本来很轻的缺口抬到地板（说出来反而变重）
   - `attachAt` 在模块加载时定，热重载后误报 channel-gap
   这些都是"新增机制"带出来的，不是原有代码退化。
3. **剩下三件的触发条件全都依赖数据**，现在做只能靠猜。

来源：《数字生命完整识海体系》《数字生命心智完整体系》《心理学植入体系》。这三份是**世界观设定集**（且自标"部分由豆包生成"），只借"机制的形状"，不当科学依据。

| # | 点 | 状态 | 说明 |
|---|---|---|---|
| ① | **缺口要能"自然释怀"** | ✅ 0.28.2 已做 | 我们的 questions 张力只涨不落（每小时 +1.5，只有 touch 才降）。半年后全堆到 100，"最重"就没区分度了。待做：超过 14 天没被碰的，张力转缓慢衰减（每天 −0.5）。**触发条件**：questions 里出现 ≥3 条张力 >80 且 30 天没碰 |
| ② | **元认知四问写进 soul 提案模板** | ✅ 0.28.1 已做 | 提案里新增「元认知四问（人审时逐条过）」：本心还是情绪 / 有没有盲区执念 / 价值观要不要调（答：不要）/ 离理想自我差什么 |
| ③ | **成熟度分级（她长到哪了）** | ✅ 0.28.1 已做 | memory stats 首行：L0 未开始 / L1 萌芽（有点无自述）/ L2 成长（有自述）/ L3 成熟（有自述 + 走过修订）；另加"停滞"叠加标记（30 天无新点 / 60 天无新自述） |
