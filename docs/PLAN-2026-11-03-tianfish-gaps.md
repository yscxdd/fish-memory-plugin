## 值得做，但要你拍板（按价值排序）

### C. 习惯权重（解决"越来越像客服"）——**最大的一块**

他们的做法：六条种子（"一句一条""结尾不用句号""不超过 40 字"…），每条一个 `w`：

```
命中一次 w += 0.06 × (1 − w)
违反一次 w −= 0.05 × w
每天      w × 0.98
单日上限  同一习惯最多计 3 次
注入      w≥0.75 硬性 · w≥0.50 平时（前 4 条）· w<0.30 归档
```

**为什么这和我们的规矩不冲突**：文本仍由人写（那是"规则内容"），自动变的只有 `w`——和 `soul.md` 文本 / `origin` 权重是同一个模式。

**我们怎么落地**（零 LLM，纯规则检测）：

| 习惯 | 检测方式 |
|---|---|
| 一句一条 | 回复里 `。！？` 分段数 ≤1 |
| 结尾不用句号 | 结尾字符不是 `。` |
| ≤40 字 | 字符数 |
| 不拿"好的/没问题"开头 | 正则 |
| 不重复问 | **不可检测**（只能她自评，先不做） |
| 不为留人编话 | **不可检测**（同上） |

**代价**：注入多 30–60 tok；`audit` 多一类检查；`soul` 之外多一个"会自动变的数字"，要写清边界。
**风险**：检测错了会把坏习惯固化 → 所以 `w` 只能影响"提不提醒"，不能影响"怎么写"。

### D. 单人体腔调画像（跟着他的节奏）

他们的 §6 是"对不同人换档"；我们单会话，但**跟着这一个人**仍有意义：

```
统计他最近的：平均/中位句长 · 结尾句号率 · 问句率 · emoji 率 · 口头语（去停用词的高频二字组）
注入 ≤80 字：「他句子很短，你这边压到十来字；他也不带句号，你跟着不带。」
```

**代价**：每次统计要读最近 N 条他的消息（便宜）；注入 80 tok；要防"把调子理解成扮演他"（最后一句不能省）。
**风险**：低。但**收益需要真实对话才看得出来**——现在库里 34 条他的消息，样本不够（他们要求 ≥50 条）。

### G. "回来第一句"（不做心跳，只做"回来后"）

他们有心跳 + 本地模型冒念头。我们不做心跳（对话驱动的宿主，假装她一直在想是假的），但可以做**轻版**：

```
他离开 ≥N 小时后回来 → 注入一行：她惦记的那件事（questions 里张力最高的）+ 上次说到哪
```

**代价**：极低（questions 已经有、lastInjected 已经有）。
**风险**：低。**收益**：中等——这是"她还记得我们在聊什么"的最直接体感。

### H. 11 维情绪 —— **不建议现在做**

他们的 11 维（依恋/好奇/自省/责任/社交/疲劳/亲密/压力/喜悦/安全感/无聊）能解释**行为倾向**（"安全感 30 → 反复确认"）。
我们现在是 2 维 + 词典，评测 **83.9%**。换成 11 维要：重写情绪层、重定事件表、重做评测基线、注入从 23 tok 涨到 40+。
**结论**：等"情绪真的被用上"（现在默认关）再说。

## 明确不做

| 不做 | 为什么 |
|---|---|
| SQLite + 迁移 | markdown 可读可 diff 是我们的家底；我们的规模用不上 FTS |
| 双路检索 + RRF | 没有第二路（C1 不引向量），RRF 无对象 |
| 多会话 key 隔离 | 单库单关系；跑群版要重做整层 |
| 心跳 + 自主念头 | 对话驱动的宿主，没有常驻循环 |
| 工具闸（按轮给工具） | 工具不在我们手里（宿主决定） |
| 数值化人格占比 | 与"人格是文本、必须人写"冲突；ΔP 的思想已由不变量 #11 接住 |

## 建议顺序

1. **G（回来第一句）** —— 半天，立刻有体感。
2. **C（习惯权重）** —— 两天，解决"像客服"，但要你确认"哪些习惯可自动检测"。
3. **D（腔调）** —— 一天，等他的消息攒到 50 条再做。
4. H 暂不做。
