## 这份数怎么用

- **不是金标准**：标注是我按"人读到这句话会怎么感觉"打的；换个人标，±5% 很正常。
- **hard 档才是重点**：反讽、否定、转述、混合（"累死我了，但很值得"）。50% 说明本地词典**做不到**，别指望它安慰对。
- **别为了抬高数字改标注**：错例全部打印出来（`--wrong N`），改了词典要重跑。
- 测试里钉了地板（整体 ≥80% / easy ≥95% / hard ≥45% / MAE ≤0.4），**只能往上走，不能悄悄退**。

## 已知错在哪（10/62）

| 类型 | 例子 | 为什么难 |
|---|---|---|
| 反讽 | `太好了呢，又一次半夜被叫起来` | 字面全正，全靠语境 |
| 否定嵌套 | `没有生气，只是有点累` | 否定了"生气"，但"累"是真的 |
| 转述 | `他说他很累` / `她昨天哭了很久` | 说的是别人，他本人未必低落 |
| 隐情绪 | `算了，不说了` / `今天忙到没吃饭` | 没有一个情绪词 |
| 让步转折 | `累归累，见到你还是很高兴` | 前半负后半正，词典只看后半 |
| 时间转折 | `不开心的事终于过去了` | "不开心"是修饰语，不是当下的情绪 |

## 这一轮做了什么

1. **转折词取主句**：`累死我了，但很值得` 按"但"之后判。这一条把整体从 79.0% 提到 83.9%，hard 从 35% 到 50%。
2. **补了几个常用词**：`值得 / 还行 / 好多了 / 挺好 / 不赖`。
3. **数据集与脚本分开**：`samples/eval-emotion.jsonl`（数据）+ `scripts/eval-emotion.mjs`（算分），加样本不用改代码。

## 怎么跑

```powershell
node scripts/eval-emotion.mjs            # 人读
node scripts/eval-emotion.mjs --json     # 机器读
node scripts/eval-emotion.mjs --wrong 20 # 多看几条错例
node --test test/eval-emotion.test.js    # 地板检查（CI 会跑）
```
