## ② V2EX（标题 + 正文）

**标题**（选一个，别用"求 star"这类词）

- `我把 AI 记忆做成了一堆你能 cat 的文件`
- `零依赖的 AI 记忆插件：记忆是文件夹，不是数据库`
- `为什么我的 AI 记忆插件不用向量库（已开源，227 个测试）`

**正文**

> 现在的 AI 记忆方案（mem0、Letta/MemGPT、Zep）大多把记忆放进向量库或服务里：要跑数据库、要 embedding、要联网——你没法 `cat` 自己的记忆，也没法 `git diff` 它昨天变了什么。
>
> 我做的这个插件反过来：**记忆就是磁盘上一个文件夹**。
>
> - `00_core/` 灵魂、用户、关系、硬规则（markdown，改了什么一眼看见）
> - `10_archive/` 逐字对话（append-only JSONL，带 prev/hash 链，启动时校验有没有被改过）
> - `30_points/` 记忆点（markdown + front matter，**每条必须挂 source，指向档案里真实存在的一条消息**）
> - `50_log/` 检索日志、完整性日志、核心层变更日志
>
> 每轮对话，插件只回答一个问题："这一轮该让她想起什么？" 答案是按预算拼一段注入：核心层 700 tok、正文 300 tok、能力卡 2400 tok；装不下就 `full → 摘要 → 索引行` 逐级降级，底线类（承诺、边界）永不降级。
>
> 几个刻意的决定：
>
> - **不自动改旧记忆**。事实变了写 `invalid_at`（标记失效，历史保留），不覆盖。mem0 自己都把自动 UPDATE/DELETE 废掉了。
> - **不编造**。找不到 source 就写"找不到"。
> - **冲突不裁决**。两条互斥的记忆会同时摆出来，标明"记录里是这么说的"，由人决定。
> - **不发网络请求、无遥测**。隐私边界不在代码，在你的库被谁同步走了——所以 README 里写了备份要加密。
>
> 227 个单测、12 个闸门（完整性/召回/注入面/核心层保护）、金标 20/20，CI 跑 Windows + Linux × Node 20/22。
>
> 不需要 DSH 也能 2 分钟试跑：`git clone` → `node scripts/memory.mjs init /tmp/mem` → `gold`。
>
> 仓库：https://github.com/yscxdd/fish-memory-plugin
>
> 最有价值的反馈：**你想要它记住什么、以及在什么场景下它该闭嘴。**

## ④ Reddit `r/LocalLLaMA`（English，约 200 词）

**Title**：`I built a local-first memory plugin where memory is just files (markdown + append-only JSONL) — no vector DB, no telemetry`

> Most "AI memory" stacks put memories in a vector DB or a service: you can't `cat` it, can't `git diff` what changed yesterday, and you need embeddings + a running server.
>
> So I went the other way: **memory is a folder on disk**.
>
> - `00_core/` soul / user / relationship / rules — plain markdown
> - `10_archive/` verbatim transcript — append-only JSONL with a prev/hash chain, verified on startup
> - `30_points/` memory points — markdown + front matter, **every point must cite a message id that actually exists in the archive**
> - `50_log/` retrieval / integrity / core-change logs
>
> Each turn the plugin answers one question: "what should she remember right now?" It assembles a budgeted injection (700 tok core / 300 tok body / 2400 tok skills) and degrades `full → summary → index line` instead of truncating blindly. Pinned / boundary / promise never degrade.
>
> Deliberate choices: **no automatic rewrite** of old memories (facts change via `invalid_at`, history kept); **no fabrication** (no source → say "I don't know"); **no conflict arbitration** (both sides shown, human decides); **no network calls, no telemetry**.
>
> 227 tests, 12 self-check gates, 20/20 recall gold set, CI on Windows + Linux × Node 20/22. Zero dependencies — no `npm install`.
>
> `git clone` → `node scripts/memory.mjs init /tmp/mem` → `gold` to try it in 2 minutes.
>
> Repo: https://github.com/yscxdd/fish-memory-plugin
>
> What I'd most like feedback on: **what you'd want it to remember, and when it should shut up.**

## 回帖模板（有人问就照这个答）

| 问题 | 回答 |
|---|---|
| "和 mem0 / Letta 有什么区别？" | 它们是服务/运行时，记忆在向量库或数据库里；我们是**一个文件夹**：markdown + 只追加的 jsonl，零依赖、可 `cat`、可 `git diff`、可整包搬走。适合一对一长期陪伴，不适合多租户大规模检索。 |
| "为什么不用 embedding？" | 金标 20/20 已经够用；零依赖与可迁移更重要。等金标跌破 16/20，且证据表明是语义鸿沟而不是权重问题，才考虑（这条写进契约的「明确不做」了）。 |
| "记忆被写坏了怎么办？" | 档案有 hash 链 + 清单，启动就报；核心层有 7 天改动上限与三条金丝雀锚点；每次检索/写入都留 `50_log/`。 |
| "会不会把我的对话传出去？" | 不发任何网络请求、无遥测。隐私边界在"库被谁同步走了"，所以 README 里写了备份要加密。 |
| "怎么接入我自己的 bot？" | 现在只接了 DSH；`scripts/memory.mjs` 是独立的，`lib/render.js` 的 `assemble()` 可以直接复用来拼注入。欢迎提 PR，六条硬规矩在 `CONTRIBUTING.md`。 |
| "能商用吗？" | MIT，可以。但请先读 `SECURITY.md` 里"不算漏洞"那节，别把它当加密存储。 |
