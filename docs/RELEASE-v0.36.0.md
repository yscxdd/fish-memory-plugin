# v0.36.0 · 记得住、忘得掉、会惦记、还会被自己说过的话慢慢塑形（自 v0.21.0 起）

给 AI 伴侣的**本地**长期记忆插件。零依赖、无遥测、一个目录换机器、记忆永远是 markdown + JSON。

---

## 这六版（0.31 → 0.36）新增了什么

### 0.31 · 隐私脱敏

档案是逐字只追加的，他随手贴一个 API key 进来，那个 key 就永久躺在库里。

- **入库前脱敏**：手机号 / 身份证 / 银行卡 / 邮箱 / `sk-`·`ghp_` 密钥 / `密码：`·`api_key=` 凭据 → `[脱敏:手机号]`
- **旧档案**：`memory redact`（dry）→ `--apply`（真改，**重算 hash 链**，写 `redaction.log`）
- **体检**：`audit.redaction` 报"档案里还有几条明文"
- 规矩：幂等、保留关键词（`密码：xxx` 不会吞掉"密码"两个字）、不误伤日期与普通数字

> 一个真数据换来的决定：第一版还脱敏"裸十六进制 ≥32 位"，拿真库一跑，**17 处命中全是 sha256 校验和**——删掉这条规则，只认带前缀或带关键词的密钥。

### 0.32 · 情绪评测基线

以前只有"测试通过"，没有"判断准不准"。一个永远输出 0 的词典也能全绿。

```
62 条人工标注：三分类 83.9%（easy 100% / hard 50%）· macro F1 0.839 · MAE 0.361
```

顺手修了一条真问题：**转折词**。`累死我了，但很值得` 原来判负——现在有 `但/不过/可是/然而/只是` 就只判转折后的主句（整体 79.0% → 83.9%，hard 35% → 50%）。

剩下的错例全部公开：反讽、否定嵌套、转述、隐情绪。**这些不是加词能解决的**，所以不装。

### 0.33 · 口癖采集（只提案）

`voice.md` 里那 20 段她真说过的话，是核心层，不许代码直接改。

- `memory voice mine` 从档案里挑"她反复说、但你还没记下的句子" → `40_pending/` 提案
- `memory voice accept 1,3` 才写进 `voice.md`，并在 `core_changelog` 记一行
- 五条硬规则：只采 `assistant`（他说过的同款是回声）、逐字不改、已在 `voice.md` 不提、拒过不提、**accept 之后才写**

### 0.34 · 情境过期 / 检索去冗余 / 快照

- **`expires_at`**：`invalid_at` 是"已经失效"（要人回来改），`expires_at` 是"将会失效"（到点自动进遗忘层）。没有它，三个月后她还会以为你在加班。底线/承诺不许写，`pin: hard` 过期也不让位。
- **检索去冗余**：同一批里说的是同一件事的，只留分数最高的（dice ≥0.78 或包含率双向 ≥0.85）；没有摘要的点不参与合并。
- **`memory snapshot`**：`snapshot 改参数` → 快照；`--list`；`--restore <名> --force` 回滚。

### 0.35 · 回来第一句

他隔了一阵回来时，她记得上次说到哪：

```
<!-- 接着上次 -->他隔了 9 小时才回来。上次说到「台风天他提前下班」。<!-- /接着上次 -->
```

- ≥6 小时才算"回来"；**一次离开只说一次**；≤60 tok（实测 29）；没有主题就只说时长，不编
- 张力够重的缺口才提一句"她心里还惦记着一件事"（原文另有位置，不重复塞）

> 没做他们的"心跳 + 本地模型自己冒念头"：我们跑在对话驱动的宿主里，**假装她一直在想是假的**。

### 0.36 · 说话习惯权重

解决"她越来越像客服"（开头"好的"、一说三句、结尾带句号）。三条可检测的种子：

```
命中 w += 0.06 × (1 − w)      每天 w × 0.98
违反 w −= 0.05 × w            单日同一习惯最多计 3 次
注入 ≥0.75 硬性 · ≥0.5 平时 · <0.3 归档
```

- **文本人写、权重自动**（和 soul 文本 / origin 权重同一个模式）
- 只上三条能测的。`不重复问`、`不为留人编话` 规则判断不了，**硬上会误判**——不做
- 初始 0.45：还没证明她做得到，先不提醒

## 完整能力（0.22 → 0.36）

| 能力 | 一句话 |
|---|---|
| 记忆 | 三层（核心 / 情景 / 档案）+ FSRS 衰减 + 每轮 412 tok |
| 溯源 | `source` 必须存在，QUOTE 逐字，档案 hash 链只追加 |
| 遗忘 | 四档：active → demoted → `31_dormant/`（可复活）→ 删点留墓碑 |
| 惦记 | `questions`：张力按时间涨、说出来会松、30 天没碰会释怀 |
| 人格 | `soul.md` 锁定区 + 六道闸 + 元认知四问 + `origin` 四分类 |
| 口音 | `voice.md` 20 段逐字样本 + 采集只提案 |
| 隐私 | 入库前脱敏 + 旧档案可扫 |
| 习惯 | 三条种子，权重随她自己的表现涨落 |
| 评测 | 情绪 83.9% + 金标 20/20 + 地板钉在测试里 |
| 账本 | `memory stats`：注入均值 / 分层占比 / 门控与命中 / 每轮成本 |

## 质量

- **465 个单测**（零依赖、不联网）
- 金标 20/20、负例 0、边际 0.68
- 12 条不变量各有断言；五个离线闸门 + 12 门自检
- `selfcheck` 比对"进程里的 lib 指纹 vs 磁盘"——抓"改了代码没生效"
- CI：Windows + Linux × Node 20/22

## 升级

```powershell
cd fish-memory-plugin
git pull
node scripts/memory.mjs verify
# 插件管理器里关一次再开（lib/ 改过）
node scripts/selfcheck.mjs     # 「运行时版本」应显示 进程 lib = 磁盘 lib
```

**旧库直接可用**：`31_dormant/`、`32_purged/`、`20_state/habits.json` 都会自动创建；
旧的 `status: dormant` 点可用 `migrateLegacyDormant` 一次性迁入遗忘层。
