# samples/ — 演示素材（**不属于她的记忆**）

这三条 `M-2026-10-28-*.md` 是搭基线时放在记忆库 `_samples/` 里的演示点：台风天看海、楼下那家面、别夸她懂事。

## 它们为什么在这里，而不是在 `fish-memory/` 里

`MemoryStore.points()` 以前**同时扫** `30_points/` 和 `_samples/`（旧 `store.js:117`），
于是空库里她"检索到"的其实是演示素材。这不是假设——**2026-10-30 20:17 那轮真实注入过**：

```
retrieval.log → rendered: ["M-2026-10-28-001"]
她的注入块 → 「2026-10-28 台风天看海 / 台风夜地铁口积水到小腿，她坚持绕路去海边……」
```

而这几条的 `source` 是 `[msg-sample-00042]` 这种**档案里不存在的 msg_id**。
也就是说，她"记得"一件从没发生过的事——违反第一条边界：**不得编造未被记录的经历**。

定义本来也是分裂的：`pack.js` 把 `_samples` 排除在备份之外（"它不是记忆"），
检索却把它当记忆读（"它是记忆"）。

## v0.13.3 的处理

- 库里不再扫 `_samples/`（`store.js` 两处都改了），遗留目录即使还在也不会被读到；
- 演示素材搬到插件仓这里，**只是给人看的示例**，永远不参与注入；
- `pack.js` 仍排除 `_samples`（防旧库还留着）；
- `inject-diff` 若在库里发现遗留 `_samples/`，会提醒"不再参与检索，可以删"。

## 它们是"格式示例"，不是"她的记忆"

拿它们对照 `30_points/TEMPLATE.md` 看 front matter 长什么样是可以的；
**不要**把它们拷回 `fish-memory/`，也不要当真实记忆引用。
